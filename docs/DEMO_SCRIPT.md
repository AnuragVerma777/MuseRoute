# MuseRoute demo script — 3 minutes

Start with `uvicorn museroute.server:app --host 127.0.0.1 --port 8000`, then open `http://127.0.0.1:8000/?demo=1`. This mode replays the saved tier answers and decisions from disk; it makes no model calls. Values that are null or from legacy latency fields appear as **NOT MEASURED**.

| Time | Scene | Narration | On-screen action | UI step |
|---|---|---|---|---|
| 0:00–0:30 | Problem | “Teams evaluating Meta Muse need to inspect which tier a routing policy selects and what happened on a held-out workload. MuseRoute records that experiment; it does not claim the selected tier is better.” | Show the single-sentence problem at the top of Chat. | Open the Chat tab and point to the prompt box and six saved examples. |
| 0:30–1:00 | Evidence | “The facts file reports 45 held-out prompts, 15 in each band. Both tiers used `meta/muse-glimmer-30b` at `integrate.api.nvidia.com`. Choose an example to see its saved cheap answer, confidence when retained, routing reason, optional strong answer, final answer, and cached status.” | Click an easy preset and show the request timeline. | Click one preset; show **cached** badges and the reason in the decision step. |
| 1:00–1:25 | Cost and tier audit | “Cheap-only averaged 249.93 tokens per request and scored 66.67%. Strong-only averaged 537.33 tokens and also scored 66.67%. Latency and cost are NOT MEASURED in these cached facts; MuseRoute's complete token total is also NOT MEASURED.” | Open Compare and show the strong-only and MuseRoute answers and metric rows. | Press **Compare strong-only vs MuseRoute**; point at every **NOT MEASURED** label. |

## 30-second fallback

Open `http://127.0.0.1:8000/?demo=1`, click any preset, show the cached route timeline, then press **Compare strong-only vs MuseRoute**. Say: “This is a cache-only replay. On the 45-prompt saved holdout, cheap-only scored 66.67%, strong-only 66.67%, and MuseRoute 75.56%; the routed score is exploratory post-hoc rescoring. Complete routed tokens, latency, and cost are NOT MEASURED.” The UI does not call the models in demo mode.
